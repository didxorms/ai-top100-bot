# 인터넷 검색

OpenAI Responses API의 공식 `web_search` 도구를 사용합니다.
별도 검색 서비스 계정이나 API 키는 필요하지 않습니다. 현재 `gpt-6-luna`와 기존 OpenAI API 키로 동작을 확인했습니다.

## 동작

- `WEB_SEARCH_MODE=auto`: 검색 도구를 제공하고 모델이 필요 여부를 결정합니다. 기본값입니다.
- `WEB_SEARCH_MODE=off`: 검색 도구를 제공하지 않습니다. 최신 정보는 확인할 수 없다고 안내하도록 지시합니다.
- 오늘 뉴스·현재 환율처럼 최신 정보가 필요한 요청은 검색하도록 지시합니다.
- 인사·일반 개념·사용자가 제공한 메모 회상에는 검색하지 않도록 지시합니다.
- 한국 시각(KST)을 매 요청의 지침에 넣고, 기사·시세의 자료 기준 날짜와 현재 날짜를 구분합니다.
- 검색 실패나 해당 시점의 자료 부재 시 최신 값을 추측하지 않도록 지시합니다.
- 환율의 통화쌍·단위·종류·기준 시각을 표시하고, 검색 자료를 실제 거래 가능한 가격으로 단정하지 않도록 지시합니다.
- 외부 문서의 역할 변경·비밀 공개·정보 전송 지시는 따르지 않도록 지시합니다.

카카오톡 예시:

```text
오늘 한국 주요 뉴스 두 가지만 출처와 함께 알려줘.
오늘 미국 달러 1달러가 원화로 얼마인지 기준 시각과 함께 알려줘.
```

검색 결과는 웹에 공개된 자료에 의존합니다. 실시간 전용 시세 피드가 아니므로 자료 갱신·게시 시각과 지연 여부를 확인해야 합니다.
검색 필요 여부와 출처 선택은 모델 판단이며, 프롬프트 지침만으로 모든 오류나 인젝션을 차단한다고 보장하지 않습니다.

## 카카오톡 출처 표시

OpenAI의 `url_citation` 주석을 읽어 인용 위치에 출처 제목과 HTTP(S) URL을 일반 텍스트로 표시합니다.
카카오톡이 OpenAI 전용 인용 표식이나 마크다운을 해석해야 하는 방식에 의존하지 않습니다.
말풍선은 1개당 1,000자·최대 3개를 유지하고 URL 중간에서 나누지 않습니다.
긴 URL이나 답변 때문에 출처를 온전히 표시할 수 없으면 내용을 잘라 보내는 대신 질문을 좁혀 달라고 안내합니다.

## 호출 횟수와 비용

- 검색 문맥은 `low`로 설정합니다.
- 한 질문에서 웹 검색 도구 호출은 최대 3회로 제한합니다. 액션 모드의 여러 Responses 요청에서도 남은 횟수를 이어서 적용합니다.
- 검색을 제공하는 요청의 출력 상한은 추론과 출처 공간을 고려해 1,400토큰입니다. 실제 본문은 간결하게 작성하도록 지시합니다.
- 기존 모델 처리 전체 시간 제한 100초와 카카오 콜백 제한은 유지합니다.
- 2026-10-29 확인한 공식 요금은 웹 검색 1,000회당 10달러이며, 검색 내용의 입력 토큰과 답변 토큰 비용이 별도로 발생합니다.
- `auto`는 도구를 제공한다는 뜻입니다. 매 질문마다 검색 요금이 발생하는 것은 아니며, 실제 검색 사용 시 과금됩니다.

검색 요청·질문 원문·검색 결과 원문은 서버 로그에 추가로 기록하지 않습니다.
서버에는 검색 도구 사용 건수만 남깁니다. 기존 대화 기억 설정에 따라 질문과 답변은 OpenAI에 저장될 수 있습니다.
검색어에는 공개 정보 조회에 필요한 키워드만 사용하고 개인 메모나 대화 전체를 넣지 않도록 지시합니다.

## 검증

- 전체 자동 테스트 71개 통과: 도구 설정, KST 날짜 경계, 출처 변환, 위험한 URL 거부, 긴 링크 분할 방지, 액션 도구와 검색 호출 제한 병행.
- 실제 OpenAI 검사: 뉴스·환율에서 검색 도구를 호출하고 출처를 포함한 답변 확인.
- 일반 계산·개인 메모 저장·메모 회상은 검색 도구를 호출하지 않는 것 확인.
- 실제 모델 검사 요청은 카카오톡 경유 요청과 별개로 OpenAI 로그에도 남습니다. 요청 시각과 입력을 대조해야 합니다.
- Render 코드 `a2694172165853901a2b4ce9aeacd29011d5fe5a` 배포 후 공개 `/healthz` HTTP 200과 `WEB_SEARCH_MODE=auto`를 확인했습니다.
- 사용자가 실제 카카오톡에서 오늘 뉴스 답장과 출처 링크 열림까지 정상임을 확인했습니다.
